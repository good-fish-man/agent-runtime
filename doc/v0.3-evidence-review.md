## 2. W2-W4 gate evidence

- Browser Failure Matrix covers snapshot drift, target missing, authentication required, unknown evidence, forbidden effects, cancellation, and retry exhaustion.
- Experience privacy skips content reads when learning is disabled, redacts secret/token/private-key/basic-auth corpora, salts summary hashes, and removes payload plus derived evaluation data on deletion.
- Retrieval strictly filters owner, task type, domain, environment, failure, outcome, capability, and skill; enforces result/token/time/sensitivity budgets; and uses a JSON evidence boundary that neutralizes injected delimiters.
- Evaluation requires frozen expected outcome, environment version, snapshot hash, and protocol; accepts only `.mock.`/`.simulation`; scores baseline and candidate observations separately; fails a named candidate without offline simulator output; and persists and displays metrics, deltas, and regressions.

## 5. Database, migration, and bootstrap security

- Fresh-schema migration, owner isolation, deletion, and Evaluation round-trip tests pass.
- Existing Evaluation rows gain Baseline, Delta, and Regression columns with safe JSON defaults; migration is idempotent.
- Corrupt Metrics/Evidence JSON now returns a source-preserving error instead of silently becoming zero values.
- An isolated packaged PostgreSQL 16.13 instance completed authenticated backup, schema/data mutation, restore, value verification, and post-restore restart.
- The fixed `athena` administrator password was removed. Launcher now generates an installation-specific password in an owner-only recovery secret and injects it into Runtime Client only through the child-process environment. A migration never elevates or rewrites an existing username.

## 7. Open gates

These cannot be replaced by local engineering tests, so `v0.3.0` is not releasable yet:

1. Signed/notarized macOS installation and update evidence.
2. Authenticode-signed Windows installation and update evidence.
3. Signed Linux AppImage/package installation and update evidence.
4. Five hundred complete packaged cross-process journeys at the required success rate; neither the completed 500-cycle component soak nor the single seven-scenario packaged E2E substitutes for this.
5. One real acceptance Trace containing all ten required terminal span classes; current packaged evidence validates only device-execution spans.
6. At least 95% terminal-task Experience coverage in production-like sampling.

See [ADR-0001](./adr/0001-v0.3-semantics-carriage.md) for the protocol decision.
