# ADR-0001：v0.3 语义对象继续通过 Protocol v4 Metadata 携带

[English](./0001-v0.3-semantics-carriage.md)

| 项目 | 值 |
| --- | --- |
| 状态 | Accepted for v0.3 |
| 日期 | 2026-08-17 |
| 决策范围 | `draft/v0alpha` Effect-Centric 语义对象的运行时携带方式 |

## 背景

`v0.3` 需要在不破坏现有设备控制面的前提下验证 Outcome、Target Resolution、Policy、PlanRun、ActionAttempt 和 Verification。当前 Protocol v4 已稳定承载 Action、Observation 和设备 WebSocket；过早新增 RPC/事件协议会把仅经过 Browser 单一垂直切片验证的字段冻结成公共契约。

## 决策

1. `v0.3` 继续把 `draft/v0alpha.SemanticTrace` 放入 Protocol v4 Action arguments 和 Observation state 的保留 metadata key。
2. 不新增、不冻结 Effect-Centric Wire Protocol。`draft/v0alpha` 的字段、JSON 结构和包路径都允许在后续证据评审中变化。
3. `os_experience*` 与 `os_evaluation*` 是 Control Plane 内部实现，不是公共协议或外部数据库兼容承诺。
4. 删除没有运行证据的 `ExecutionContext.BudgetRef` 与 `SemanticTrace.ExperienceRecordRef`。Experience 关联由现有 Task/Action/Observation/Event 引用建立，不反向改写不可变执行 Trace。
5. 只生产、尚未参与决策的字段保留为 provisional，并在下一个 Actor 垂直切片前重新评审。

## 依据

- Runtime 创建 Outcome 与 Plan；Runtime Client 绑定 Policy、Actor 和 Capability；Launcher Ground Target、执行并生成 Verification；Runtime Client 将最终结果形成 Experience。
- Browser Golden Path 在同一 Session 中真实播放第二个视频，并从媒体状态而不是点击结果判定成功。
- Snapshot Drift、Target Missing、Login-required、Unknown、Forbidden Effect、Cancel 和 Retry Exhaustion 均有确定性测试。
- 完整证据见 [v0.3 Evidence Review](../v0.3-evidence-review.zh-CN.md)。

## 后果

- Protocol v4 保持稳定，旧设备无需理解新对象也能维持传输兼容。
- 新语义对象仍可严格校验，但不能被外部集成视为冻结 API。
- 新 Wire Protocol 的 ADR 只有在至少两个不同 Actor（例如 Browser 与 Desktop/File）完成生产者、消费者、失败矩阵和 Replay 证据后才可提出。
