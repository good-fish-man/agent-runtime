# ADR-0001: Carry v0.3 semantics in Protocol v4 metadata

[Simplified Chinese](./0001-v0.3-semantics-carriage.zh-CN.md)

| Item | Value |
| --- | --- |
| Status | Accepted for v0.3 |
| Date | 2026-08-17 |
| Scope | Runtime carriage of `draft/v0alpha` effect-centric semantics |

## Context

`v0.3` must validate Outcome, Target Resolution, Policy, PlanRun, ActionAttempt, and Verification without destabilizing the device control plane. Protocol v4 already carries Actions, Observations, and the device WebSocket contract. A new wire contract would prematurely freeze fields validated by only one Browser vertical slice.

## Decision

1. `v0.3` continues to carry `draft/v0alpha.SemanticTrace` in reserved Protocol v4 Action-argument and Observation-state metadata keys.
2. No effect-centric wire protocol is introduced or frozen. `draft/v0alpha` fields, JSON shape, and package path remain changeable after evidence review.
3. `os_experience*` and `os_evaluation*` remain Control Plane implementation details, not public protocol or external database compatibility commitments.
4. Remove the unsubstantiated `ExecutionContext.BudgetRef` and `SemanticTrace.ExperienceRecordRef`. Experience correlation uses existing Task, Action, Observation, and Event references without mutating an immutable execution trace.
5. Producer-only fields remain provisional and must be reviewed before the next actor vertical slice.

## Evidence

- Runtime creates Outcome and Plan; Runtime Client binds Policy, Actor, and Capability; Launcher grounds the target, executes, and verifies effects; Runtime Client derives Experience from the final result.
- The Browser Golden Path really plays the second video in one session and determines success from media state rather than click completion.
- Snapshot drift, target missing, login-required, unknown evidence, forbidden effects, cancellation, and retry exhaustion have deterministic tests.
- See the [v0.3 Evidence Review](../v0.3-evidence-review.md).

## Consequences

- Protocol v4 stays stable and older devices can transport the metadata without understanding it.
- New semantic objects remain strictly validated but are not a frozen external API.
- A new wire-protocol ADR may be proposed only after at least two distinct actors, such as Browser and Desktop/File, have producer, consumer, failure-matrix, and replay evidence.
