## 1. 端到端证据

| 链路 | 生产者 | 消费者/验证者 | 证据 |
| --- | --- | --- | --- |
| Outcome + Plan | `agent-runtime/internal/effectspec` | Runtime Client、Launcher | 浏览器目标、Desired/Must Preserve/Forbidden Effect 与不可变 Plan Hash 测试 |
| Policy + ExecutionContext | Runtime Client | Launcher 与严格校验器 | Policy 绑定 World Read Set；设备和 Capability 绑定写入 ActorBindings |
| TargetResolution + Affordance | Launcher | Effect Verification、Experience Trace | Snapshot 绑定、精确实体、Evidence、TTL 与失效测试 |
| ActionAttempt + Observation | Runtime Client / Launcher | Control Plane | 取消、等待、失败和成功保持独立终态；同幂等键只发送一次 |
| VerificationResult | Launcher | Runtime Client、Experience | 四态聚合；Forbidden Effect 优先；Action 成功不等于 Outcome 成功 |
| Experience | Runtime Client | Retrieval、Evaluation、Frontend | 脱敏、Owner 隔离、Retention/Delete、Cost/Usage、结构化检索维度 |

## 2. W2-W4 门禁证据

- Browser Failure Matrix：Snapshot Drift、Target Missing、Authentication Required、Unknown、Forbidden Effect、Cancel、Retry Exhaustion。
- Experience Privacy：学习关闭时不读取内容；Secret/Token/Private Key/Basic Auth 语料脱敏；摘要哈希加盐；删除后 Payload 与派生 Evaluation 不可读取。
- Retrieval：Owner、Task Type、Domain、Environment、Failure、Outcome、Capability、Skill 严格过滤；数量、Token、时间、敏感度预算；历史内容使用 JSON 证据边界，不能伪造结束标记。
- Evaluation：Fixture 强制绑定 Expected Outcome、环境版本、Snapshot Hash 和协议；只接受 `.mock.`/`.simulation`；基线与候选 Observation 分别评分；命名候选没有离线模拟输出时硬失败；指标、差值及 Regression 持久化并展示。

## 5. 数据库、迁移与引导安全

- 新库 AutoMigrate、Owner Isolation、删除和 Evaluation 往返测试通过。
- 已有 Evaluation 行升级时自动增加 Baseline、Delta、Regression 字段，并使用安全 JSON 默认值；迁移幂等。
- 损坏的 Metrics/Evidence JSON 不再静默变成零值，而是返回带来源的错误。
- 隔离的打包 PostgreSQL 16.13 实例完成认证备份、Schema/Data 变更、恢复、值校验和恢复后重启。
- 已移除固定的 `athena` 管理员密码。Launcher 为每个安装生成独立密码，保存在仅 Owner 可读的恢复 Secret 中，并只通过子进程环境注入 Runtime Client；迁移不会提权或改写已有同名用户。

## 7. 未关闭门禁

这些项目不能由当前单机工程测试替代，因此 `v0.3.0` 不能发布：

1. macOS 签名/公证安装与更新证据。
2. Windows Authenticode 签名安装与更新证据。
3. Linux 签名 AppImage/Package 安装与更新证据。
4. 500 次完整打包跨进程 Journey 达到目标成功率；现有 500 轮组件 Soak 和单次 7 场景打包 E2E 都不能替代该门禁。
5. 一条真实验收 Trace 同时覆盖全部 10 类必需结束 Span；当前打包证据只验证设备执行侧 Span。
6. 生产近似采样中终态 Task 的 Experience 覆盖率达到 95%。
