[English](./v0.2-release-readiness.md)

本报告严格区分“代码实现完成”和“正式版验收完成”。在所有外部门禁留下可审计记录之前，架构集成线只能作为 Release Candidate 开发线。

| 审批边界 | 已实现 | `ASK_USER` 持久化、按 Owner 隔离、Revision 校验，审批前不会发送到设备 |

## 必需 Span 映射

| Span | 所属服务 | 边界 |
| --- | --- | --- |
| `intent.parse` | Agent Runtime | 自然语言请求转结构化 Intent |
| `route.plan` | Agent Runtime | Intent 转主路由、能力及 Fallback |
| `world.query` | Runtime Client | 查询持久化 World State |
| `model.invoke` | Agent Runtime | 流式/非流式模型调用、Token 与结束原因 |
| `action.policy` | Runtime Client | 持久化或派发前的策略/风险校验 |
| `action.dispatch` | Runtime Client | 幂等、设备路由、持久化派发及等待 Observation |
| `device.execute` | Launcher | 设备侧真实执行与 Journal 结果 |
| `perception.observe` | Launcher | 浏览器执行及其受预算约束的页面 Observation |
| `world.apply` | Runtime Client | Observation/Evidence 入库及 World Patch 投影 |
| `task.verify` | Runtime Client | Observation 关联校验与 Task 状态迁移 |

每个结束 Span 都包含 Trace ID、Span ID、UTC 结束时间、`cost_ms`、`cost_us`、结果字段；失败时只输出一次完整错误链。真实 E2E 后使用以下命令验收：

```bash
./scripts/verify-v0.2-spans.sh ~/.athena/logs
# 也可以指定必须验收的 Trace：
./scripts/verify-v0.2-spans.sh ~/.athena/logs arc-your-trace-id
```

验收脚本要求十个结束 Span 全部属于同一个 Trace ID，互不相关或过期的零散 Trace 不能通过门禁。

## 本地验证

每个 Release Candidate 必须执行：

```bash
cd athena-protocol && make check
cd logx && go test ./...
cd agent-runtime && go test ./...
cd agent-runtime-client && go test ./...
cd athena-launcher && go test ./...
cd frontend/agent-ui && npm run protocol:check && npm run lint && npm run build
```
